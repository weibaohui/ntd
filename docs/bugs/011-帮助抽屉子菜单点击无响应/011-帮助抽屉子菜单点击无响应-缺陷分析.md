# NTD-011 帮助抽屉子菜单点击无响应 — 缺陷分析

| 修改人 | 修改时间 | 修改内容 |
|--------|---------|---------|
| AI(pi) | 2026-08-02 | 初始版本 |
| AI(pi) | 2026-08-02 | PR 评审 #978：补充 ```text 语言标识（MD040） |

---

## 1. 代码链路

```text
LeftRail「帮助」按钮
  → App.tsx: helpDrawerOpen = true
    → HelpDrawer（左 Tree + 右 HelpContentRenderer）
      → 选中节点 selectedKey
        → resolveDocFile(selectedKey) 解析出 md 文件名        ✅ 正常
          → loadHelpDoc(docFile) 取 md 内容                    ❌ 返回函数而非字符串
            → HelpContentRenderer: <XMarkdown content={source} />
              → XMarkdown 校验输入类型                          ❌ 拒绝渲染，console 报错
```

## 2. 根因 1（核心）：`import.meta.glob` 漏配 `eager: true`

**位置**：`frontend/src/help/useHelpContent.ts:16`

```ts
const allDocs = import.meta.glob('./pages/*.md', {
  query: '?raw',
  import: 'default',
}) as unknown as Record<string, string>;
```

- Vite 的 `import.meta.glob` **默认为懒加载**：返回的对象值是 `() => Promise<string>` 加载函数，并非模块内容本身；只有显式传 `eager: true` 才会在构建时直接内联为字符串。
- 代码意图（见文件头注释）是「构建时把 md 以 raw string 打进 bundle，运行时按文件名取出，无需 fetch」——漏写 `eager: true` 导致实际行为与设计意图相反。
- `as unknown as Record<string, string>` 双重强转跳过了 TypeScript 类型检查，编译期零报错，问题被隐藏到运行时。
- 运行时：`loadHelpDoc()` 返回函数 → `docSource` 为函数（真值）→ 不走 `Empty` 分支 → `XMarkdown` 收到函数类型的 `content` → 校验失败打 console 错误并渲染空白。

**用户感知**：点任何节点右侧都空白 → 「点了没反应」。

## 3. 根因 2（交互）：antd Tree 点标题不展开子节点

**位置**：`frontend/src/help/HelpDrawer.tsx` 的 `handleSelect`

- antd Tree 默认行为：点击节点标题仅触发 `onSelect`（选中），展开/收起只能点击 switcher 小箭头。
- 帮助树是「页面 → 功能点」菜单语义，用户习惯点击菜单文字展开子菜单；小箭头点击目标小、不易发现。
- 当前 `handleSelect` 只更新 `selectedKey`，不同步更新 `expandedKeys`，故点标题时子菜单保持收起。

**用户感知**：点父节点标题子菜单不展开 → 「子菜单点不开」。

## 4. 两个根因的叠加效应

| 用户操作 | 根因 1（内容空白） | 根因 2（不展开） | 用户感知 |
|---------|-------------------|-----------------|---------|
| 点父节点标题 | 右侧空白 | 子菜单不展开 | 「点不开、没反应」 |
| 点箭头再点子节点 | 右侧空白 | （正常展开） | 「点了没反应」 |

两根因相互强化，导致「帮助菜单完全不可用」的整体观感。

## 5. 修复方向

1. `useHelpContent.ts`：glob 选项补 `eager: true`，使 `allDocs` 值为 raw string，回归设计意图（一行修复）。
2. `HelpDrawer.tsx`：`handleSelect` 中当选中页面节点（`p:` 前缀）且未展开时，将其并入 `expandedKeys`，实现「点标题即展开」；收起行为仍由 switcher 箭头承担，避免与选中冲突。

## 6. 验证方式

- Playwright：打开帮助抽屉 → 断言右侧渲染出 md 标题；点父节点标题 → 断言子菜单展开；点功能点子节点 → 断言内容切换且 console 无 X-Markdown 错误。
- `cd frontend && npx tsc --noEmit` 零错误。
