## 4. 实际行为（Observed Behavior）

- 抽屉正常打开，左侧树形菜单正常展示「页面 → 功能点」两级节点
- 点击任意树节点（含子菜单节点）后，**右侧内容区始终空白**，不渲染任何帮助文档
- 浏览器 console 出现错误：`X-Markdown: input must be string, not function.`（每次选中节点均出现）
- 点击父节点「标题文字」时，子菜单不展开（仅切换选中态）；只有点击节点左侧小箭头（switcher）才展开
- 发生频率：必现

Playwright 实测事实（`frontend/tests/check_help_tree.spec.ts`）：
- 打开抽屉后右侧内容容器 `textContent` 为空字符串，无 `h1/h2/h3` 元素
- 点击父节点标题后子菜单未展开；点击 switcher 箭头后子菜单展开

## 5. 期望行为（Expected Behavior）

- 点击树中任意节点后，右侧内容区应渲染该节点对应的 md 帮助文档（可见标题、正文）
- 点击父节点标题文字时，子菜单应随之展开（符合常规菜单交互习惯）
- 浏览器 console 不应出现 X-Markdown 输入类型错误

## 6. 行为偏差定义（Deviation）

> 在【打开帮助抽屉并点击树节点】下，系统实际执行了【右侧内容区空白、console 报 X-Markdown 输入类型错误、点标题不展开子菜单】，但期望执行的是【渲染对应 md 文档且点标题即可展开子菜单】
