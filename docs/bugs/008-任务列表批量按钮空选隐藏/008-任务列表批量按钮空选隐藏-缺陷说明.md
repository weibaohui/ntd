## 4. 实际行为（Observed Behavior）

- 实际行为：任务列表空选时，table 上方不显示「批量」按钮；只有勾选行之后才显示。
- 对照行为：事项列表（`/#/todos`）空选时仍显示「批量」按钮，但按钮与菜单项处于不可点击状态。
- 发生频率：必现。

## 5. 期望行为（Expected Behavior）

- 系统应当执行：任务列表「批量」按钮保持一直显示；空选时按钮和菜单项不可点击，有选中后恢复可点击。
- 明确允许的正常结果范围：不改变批量删除入口、不改变既有确认弹窗逻辑。

## 6. 行为偏差定义（Deviation）

> **在任务列表空选状态下，系统实际隐藏了批量按钮；但期望像事项列表一样一直显示批量按钮，只是空选时禁用**
