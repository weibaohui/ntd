## 1. 修复内容

**改动文件**：

- `frontend/src/components/tasks/TaskDetailPanel.tsx`
- `frontend/tests/ntd007-task-process-gate-detail.spec.ts`

| 改动点 | 说明 |
|--------|------|
| `gate_config` 类型补全 | `StepInfo.gate_config` 从 `{ name, type }[]` 改为 `GateDefinition[]`，接收后端已返回的完整门禁 JSON |
| 门禁详情文本 | 新增 `gateDetailText`：`ai_criteria_review` 显示 `阈值 ≥ N 分` 与正数 `timeout_secs`；`artifact_present` 显示产物名；`script_check` 显示脚本路径 |
| 门禁 Tag 渲染 | 从 `名称 (类型)` 改为 `名称 (类型 · 关键判定条件)`；无额外参数时保持原样式 |
| 回归测试 | 新增 Playwright spec，自种子 todo/loop/step/task，验证「工艺要求」tab 显示 `AI 评审 · 阈值 ≥ 80 分；等待 ≤ 30s` |

## 2. 与缺陷分析的对应关系

| 根因 | 修复手段 |
|------|---------|
| 前端类型只声明 `name/type`，渲染也只使用这两个字段 | 复用 `GateDefinition` 类型并按类型展示关键配置 |
| AI 评审阈值 `min_score` 已在接口 JSON 中但未展示 | `ai_criteria_review` 分支显式渲染 `阈值 ≥ N 分` |
