## 4. 实际行为（Observed Behavior）

- 实际行为 1：任务列表工具栏中「批量」按钮不是第一个操作控件，当前顺序为状态筛选 Select 在前、「批量」按钮在后。
- 实际行为 2：点击「批量 → 删除」后弹出的确认窗口未正确适配暗色 / 亮色主题，表现为确认窗视觉与当前主题不一致。
- 返回结果 / 错误码 / 异常信息：无接口错误；属于 UI 结构与主题适配问题。
- 发生频率：必现。

## 5. 期望行为（Expected Behavior）

- 系统应当执行 1：任务列表工具栏中「批量」按钮放在第一个位置，状态筛选等其他控件排在其后。
- 系统应当执行 2：批量删除确认窗口与全站主题机制一致，在暗色和亮色主题下都使用当前 `ConfigProvider` 主题 token 渲染。
- 明确允许的正常结果范围：不改变批量删除接口参数、不改变删除确认文案含义、不影响事项 / 环路列表的既有批量操作。

## 6. 行为偏差定义（Deviation）

> **在任务列表已勾选任务的条件下，系统实际把状态筛选放在批量按钮之前，并且批量删除确认窗未随主题正确渲染；但期望批量按钮位于工具栏首位，且确认窗在亮/暗主题下都按当前主题渲染**
