## 5. 既有测试的处置说明

`frontend/tests/onboarding.spec.ts`（026 需求）在本分支实测结果为 **6 通过 / 7 失败**，7 个失败全部确认为**先于本需求就存在的问题**，与本 diff 无关（以 2026-07-27 同一次运行日志为准）：

| TC-09 | 断言的 `onboarding-detail-snapshot` / `onboarding-detail-empty` 在 main 源码中不存在 | 存量 testid 失效 |
| TC-10 | 断言的 `onboarding-flow-node-*` 所属 `QuickStartFlow` 组件未在 ConceptNavPage 挂载 | 存量组件下线 |
| TC-07 | 卡片徽标依赖后端 API，验证环境未启动 18088 后端（vite 代理 500） | 环境限制 |

**存活的 6 个用例**（TC-04 / TC-06 / TC-08 / TC-12 / TC-13 + TC-03）通过，证明本改动未引入回归。存量失效用例的清理建议另行开缺陷单，不在本需求范围。

## 7. 风险与降级

| 风险 | 降级 |
|------|------|
| Vite dev 下后端 API 不可达导致页面部分骨架屏 | 关系图纯静态，断言只针对图与 Drawer，不受影响 |
| hover 后 fill 断言依赖 0.2s CSS transition | fill 是 SVG attribute（React 受控），非 CSS 动画，hover 后立即可读，无需 wait |
| URL query 参数顺序差异 | kanban 仅 mode 一个参数，直接全串匹配 `#/memorial?mode=kanban`；若未来加参数改正则 |
