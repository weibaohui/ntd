## 1. 测试范围

本文档覆盖 `026-概念导航首页` 功能的 Playwright 功能测试设计与验收要点。

**测试类型**：Playwright E2E（前端 UI 交互验证）
**测试目录**：`frontend/tests/`（强制约定，禁止散落到 `/tmp/` 或根目录）
**配置文件**：`frontend/playwright.config.ts`（`testDir` 指向 `frontend/tests`）

---

## 2. 测试前置条件

| 条件 | 说明 |
|------|------|
| 开发服务运行 | `make dev` 启动，监听 `http://localhost:18088` |
| 数据库有数据 | 至少 1 个工艺模板 + 1 个环路 + 1 个事项 + 1 个任务（验证数据快照用） |
| localStorage 干净 | 每个用例前 `localStorage.clear()`，避免上次 onboarding 标记干扰 |
| 默认入口 | `http://localhost:18088/#/items`（验证首次跳转用） |

---

## 3. 测试用例清单

### TC-01：首次打开自动跳转导航首页

**步骤**：
1. `localStorage.clear()`
2. 访问 `http://localhost:18088/#/items`
3. 等 1s

**预期**：
- URL hash 变为 `#/onboarding`
- 页面可见 `PageCard` title="NTD 概念导航"
- Hero 区可见「跳过引导」按钮

**data-testid**：`onboarding-page`、`onboarding-skip-btn`

---

### TC-02：跳过引导写 localStorage 并跳转仪表盘

**步骤**：
1. 从 TC-01 进入导航首页
2. 点 `onboarding-skip-btn`
3. 等 1s

**预期**：
- URL hash 变为 `#/dashboard`
- `localStorage['ntd_onboarding_completed']` === `'true'`

---

### TC-03：老用户不自动跳转

**步骤**：
1. `localStorage.setItem('ntd_onboarding_completed', 'true')`
2. 访问 `http://localhost:18088/#/items`
3. 等 1s

**预期**：
- URL hash 保持 `#/items`，不跳 onboarding

---

### TC-04：LeftRail「概览」区有「导航」入口

**步骤**：
1. 访问任意页面
2. 找 LeftRail「概览」区
3. 检查是否有「导航」按钮

**预期**：
- 可见 `data-testid="left-rail-onboarding"` 按钮
- 点击后 URL hash 变为 `#/onboarding`

---

### TC-05：概念关系图渲染 + 点击节点弹 Drawer

**步骤**：
1. 进入导航首页
2. 滚到「关系图」section
3. 检查 SVG 可见
4. 点 `data-testid="onboarding-graph-node-loop"` 节点

**预期**：
- SVG `<svg>` 元素存在
- 右侧 Drawer 打开，title 含「环路」
- Drawer 内可见字段表 + 「去环路页」按钮 `onboarding-graph-drawer-goto`

---

### TC-06：关系图节点 hover 高亮关联节点

**步骤**：
1. 进入导航首页
2. hover `onboarding-graph-node-loop` 节点
3. 检查 `onboarding-graph-node-process` 和 `onboarding-graph-node-todo` 的 class

**预期**：
- 关联节点 class 含 `ntd-onboarding-graph-highlight`
- 连线 class 含 `ntd-onboarding-edge-active`

---

### TC-07：概念卡片网格渲染 6 张 + 数量徽标

**步骤**：
1. 进入导航首页
2. 滚到「概念详解」section
3. 检查卡片数量 + 徽标

**预期**：
- 6 张 `data-testid="onboarding-card-xxx"`（process/loop/todo/task/executor/expert）
- 工艺卡片右上角徽标显示当前工艺数量（如「3」）

---

### TC-08：点击卡片平滑滚动到对应说明区

**步骤**：
1. 点 `onboarding-card-process`
2. 等 1s（smooth scroll）

**预期**：
- 页面滚动到 `<section id="concept-process">` 可见
- 该 section 在视口顶部

---

### TC-09：详细说明区展示真实数据快照

**步骤**：
1. 滚到 `<section id="concept-process">`
2. 检查右栏

**预期**：
- 右栏展示当前 workspace 的真实工艺记录 YAML 片段（非「暂无数据」空态）
- 底部有「去工艺页」按钮 `onboarding-detail-goto-process`

---

### TC-10：快速开始 5 步流程图 + 完成状态

**步骤**：
1. 滚到「快速开始」section
2. 检查 5 个圆形节点 + 状态

**预期**：
- 5 个 `data-testid="onboarding-flow-node-1"` 到 `-5`
- 已有数据的步骤显示 ✓ 图标，未完成显示 ○
- 点步骤 3 节点 → URL hash 变为 `#/tasks`

---

### TC-11：sticky Tab 滚动自动高亮

**步骤**：
1. 进入导航首页
2. 滚到「概念详解」section
3. 检查 sticky Tab

**预期**：
- sticky Tab 第 2 项（概念详解）class 含 `ntd-onboarding-tab-active`

---

### TC-12：prefers-reduced-motion 动画降级

**步骤**：
1. `chromium.launch()`
2. `context = browser.newContext({ reducedMotion: 'reduce' })`
3. 访问导航首页
4. 检查关系图连线

**预期**：
- 连线无 `animation` 样式（或 `animation: none`）
- 卡片无 `transition`

---

### TC-13：空态处理（无数据系统）

**步骤**：
1. 切到空 workspace（无任何工艺/环路/任务）
2. 进入导航首页
3. 滚到详细说明区

**预期**：
- 工艺区右栏展示「暂无数据，去工艺页创建」+ 跳转按钮
- 卡片徽标显示「0」

## 7. 风险与降级

| 风险 | 降级 |
|------|------|
| IntersectionObserver 在 CI headless 可能不触发 | TC-11 标记为 `test.skip` 若 CI 不稳定 |
| 数据快照依赖真实数据 | TC-09 需在有数据环境跑；空环境跑 TC-13 |
| sticky Tab 滚动定位精度 | 容差 ±100px，不要求像素精确 |
| reduced-motion API 兼容 | Playwright `reducedMotion: 'reduce'` 支持 chromium/webkit/firefox |
