# 1. 测试目标

验证飞书 `/help` 控制台「任务」「工艺」两个新 Tab 的正确性，覆盖：

1. **卡片渲染**：6 Tab 齐全、当前 Tab 高亮、任务页按钮/委派无按钮、工艺页纯查看、空态占位、分页按钮。
2. **回调解析**：`act:/runtask`、`nav:/tasks`、`nav:/processes` 及异常输入回退。
3. **任务可执行判定**：归属 / 执行模式 / loop_id 三重校验各分支。
4. **条目映射**：任务状态图标四态 + 回退、执行方式标签、工艺 meta 拼接。
5. **编译与回归**：clippy 零告警、全量测试通过。
