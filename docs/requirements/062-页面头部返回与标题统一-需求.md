## 背景

各详情/子页面的「返回」按钮位置、文案、样式不一致，详情页标题格式也不统一，用户体验割裂。
经全量排查，现状如下。

### 现状问题 1：返回按钮 8 处实现、4 种位置、3 种文案、3 种样式

| 页面 | 位置 | 文案 | 样式 |
|------|------|------|------|
| TodoDetailPage 事项详情 | titleSuffix（标题右侧） | 返回列表 | `small + text` + ←图标 |
| LoopDetailPage 环路详情 | titleSuffix（标题右侧） | 返回列表 | `small + text` + ←图标 |
| TaskDetailPage 任务详情 | titleSuffix（标题右侧） | 返回列表 | `small + text` + ←图标 |
| TasksPage 内嵌详情分支 | titleSuffix（标题右侧） | 返回列表 | `small + text` + ←图标 |
| TodoPostPage 帖子页 | extra（右上角） | 返回 | `text` 默认大小 + ←图标 |
| WikiViewPage | extra（右上角） | ← 回到黑板 | 原生 `<button>` 手写内联样式 |
| ProcessEditor 工艺编辑器 | 自建 Toolbar 右上 | 返回 | 默认按钮（非 text） |
| WorkspaceLoopConfigPage 环路配置 | icon 插槽（标题最左） | 无文字纯图标 | `small + text` + ←图标 |

移动端另外问题：`MobileHeader` 只在 todos/loops 详情显示返回按钮，tasks 详情被遗漏。

### 现状问题 2：详情页标题 6 种格式并存

| 页面 | 标题 |
|------|------|
| TodoDetailPage | `事项 #{id}: {具体标题}` |
| TaskDetailPage | `任务 #{id}: {具体标题}` |
| TasksPage 内嵌详情 | 固定「任务详情」（无 ID 无标题） |
| LoopDetailPage | `环路 #{id}`（LoopDto 有 `name` 字段但未展示） |
| TodoPostPage | `{具体标题}`，fallback `事项 #{id}`（有标题时反而丢模块名和 ID） |
| WikiViewPage | `{slug}`（纯具体名） |
| WorkspaceLoopConfigPage | `{workspace.name} - 环路配置`（名称在前、功能在后） |
| ProcessEditor | `{displayName} ({processName})`（自建 Toolbar） |

列表页标题（纯模块名：事项/任务/环路/工艺/会话…）本身已统一，不在本次范围内。

## 需求条目（已与用户确认，选择 1b2a3c4a）

1. **R1 返回按钮位置统一**：所有子页面返回按钮统一放在页头**右上角 extra 区最右端**（固定锚点，操作按钮在其左侧）。
2. **R2 标题格式统一**：详情/子页面标题统一为 `模块名 #{id}: {具体名称}`；无 id 的页面用 `模块名: {具体名称}`。分隔符统一为半角冒号 `:` 后跟一个空格（与既有 TodoDetail/TaskDetail 实现一致）。
3. **R3 改造范围（全量）**：
   - 桌面端 8 处返回按钮 + 全部详情页标题；
   - 移动端 `MobileHeader` 补齐 tasks 详情返回；
   - ProcessEditor 自建 Toolbar 同步对齐（样式、位置、文案、标题格式）。
4. **R4 公共组件形态**：增强 `PageCard`，新增 `onBack?: () => void` 与 `backLabel?: string` props，由 PageCard 内部统一渲染返回按钮到 extra 最右端；各页面只传参，不再手写返回按钮。
5. **R5 返回按钮样式与文案**：统一 `<Button size="small" type="text" icon={<ArrowLeftOutlined />}>`；文案默认「返回列表」，返回目标不是列表时（帖子页→事项详情、Wiki→黑板）用「返回」。

## 验收标准

- 8 处子页面返回按钮全部位于右上角、样式一致、无原生 button 残留。
- 详情页标题全部符合 R2 格式；LoopDetailPage 标题展示环路名称。
- 移动端 tasks 详情页 MobileHeader 出现返回按钮。
- `cd frontend && npx tsc --noEmit` 零错误。
- Playwright 逐页截图验证通过。
