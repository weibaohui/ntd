## 3. 人工验收要点

以下项需人工在浏览器实操确认（Playwright 无法判定主观体验）：

### 3.1 视觉一致性

- [ ] PageCard 外壳与其他页（事项/环路/工艺）视觉一致
- [ ] Hero 区渐变背景 + 白字对比度 ≥ 4.5:1
- [ ] sticky Tab 粘在内容区顶部，滚动时不抖动
- [ ] 6 张卡片差异化可视化隐喻清晰可辨（3 圆点/循环箭头/卡片堆叠/闪电/终端/人形）
- [ ] 关系图节点圆形 + 中文标签居中，hover 高亮过渡流畅
- [ ] Drawer 字段表单列展示，不溢出
- [ ] 快速开始流程图横向 5 步等距，连线箭头清晰

### 3.2 交互细节

- [ ] 关系图节点 hover 时关联节点 + 连线同时高亮，延迟 < 100ms
- [ ] 关系图节点点击 Drawer 弹出动画流畅，关闭可重复打开
- [ ] 卡片 hover 上浮 2px + 阴影增强，transition 200ms
- [ ] 卡片点击后平滑滚动到说明区，不跳闪
- [ ] sticky Tab 点击后平滑滚动到对应 section
- [ ] 快速开始节点点击跳转后 LeftRail 高亮状态正确

### 3.3 真实数据快照

- [ ] 工艺说明区右栏展示当前 workspace 的真实工艺 YAML 片段（非「暂无数据」）
- [ ] 环路说明区展示真实环路记录 + 触发器列表
- [ ] 事项说明区展示真实 todo 记录含 executor/expert/model 字段
- [ ] 任务说明区展示真实 task 记录
- [ ] 执行器说明区展示真实 executor 记录
- [ ] 专家说明区展示真实 expert 记录
- [ ] 空态时展示 YAML 示例 + 「去 XX 页创建」跳转入口

### 3.4 空态兜底

- [ ] 切到无数据 workspace 时，6 个说明区右栏均展示空态文案 + 跳转入口
- [ ] 卡片徽标显示「0」而非消失
- [ ] 快速开始 5 步全显示「○ 未完成」

### 3.5 移动端降级（YAGNI 阶段，仅确认不崩）

- [ ] 移动端访问 `/#/onboarding` 页面可渲染（布局降级为纵向即可）
- [ ] 关系图 SVG 可横向滚动（不溢出截断）
- [ ] 卡片网格变单列
- [ ] 详细说明区左右分栏变上下堆叠

## 6. 已知限制与待改进

1. **关系图节点坐标硬编码**：不响应式重排，小屏溢出靠 `overflow-x: auto` 兜底。后续若需响应式可引入 reactflow。
2. **数据快照只拉一条**：不展示全量列表，避免变成「另一个工艺页」。后续可加「查看全部」跳转。
3. **快速开始步骤 5 简化判断**：与步骤 4 同源（完整实现需扫审计 API，YAGNI 阶段先简化）。
4. **TC-11 放宽判定**：IntersectionObserver 在 headless 下 rootMargin 精度不稳，测试只验证「任一 tab 高亮」而非「第 2 个高亮」。
5. **移动端未做独立组件**：降级为纵向布局，未做 `ConceptNavMobilePage`。
