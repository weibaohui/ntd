# 049-新建任务下拉显示工艺信息-实现总结

| 修改人 | 修改时间 | 修改内容 |
|--------|---------|---------|
| pi | 2026-07-31 | 初始版本 |

## 1. 概述

「新建任务」弹窗（`/#/tasks` → 新建）的工艺环路下拉选项，由 041 格式 `#<环路ID> <环路名称>`
升级为 `#<环路ID> 环路名称（#工艺ID 工艺名称 工艺版本）`，用户在下拉中即可区分同名环路来自哪个工艺的哪个版本。

纯前端改动，后端零改动（041 已在 `list_loops_v1` 注入工艺字段）。

需求文档：`docs/requirements/049-新建任务下拉显示工艺信息-需求.md`
设计文档：`docs/design/049-新建任务下拉显示工艺信息-设计.md`

## 2. 与需求的对应关系

| 需求条目 | 实现 |
|---------|------|
| 下拉 label 改为 `#<环路ID> 环路名称（#工艺ID 工艺名称 工艺版本）` | `constants.tsx::loopOptionLabel` 拼装，`CreateTaskModal` 使用 |
| display_name → name → `#<工艺ID>` 逐级回退 | `loopOptionLabel` 内实现，口径与 `formatProcessText` 一致 |
| 版本缺失 `—` 占位 | `loopOptionLabel` 内实现 |
| 无工艺来源退化 041 格式 | `loopOptionLabel` 防御分支（`process_template_id == null`） |
| 纯前端改动 | 仅 `TasksPage.tsx` 透传字段，API 零改动 |

## 3. 关键实现点

- **`frontend/src/components/tasks/constants.tsx`**：`LoopLite` 扩展 4 个工艺可选字段
  （`process_template_id` / `process_template_display_name` / `process_template_name` / `process_template_version`）；
  新增纯函数 `loopOptionLabel(l)` 负责 label 拼装与全部回退逻辑（与 041 `loopProcessText` 同模式，便于单测）。
- **`frontend/src/components/tasks/TasksPage.tsx`**：`setLoops` 映射透传 4 个工艺字段
  （此前被 `.map(({id, name}))` 裁掉，这是「接口有数据但下拉看不到」的根因）。
- **`frontend/src/components/tasks/CreateTaskModal.tsx`**：Select option `label` 由模板字符串改为 `loopOptionLabel(l)`。
- **未复用 `formatProcessText`**：其输出为表格列口径 `#id-名称-版本`（中划线），与本需求下拉行内空格分隔格式不同；仅复用其回退口径。

## 4. 验证结果

- `npx tsc --noEmit`：零错误。
- `npx vitest run`：24 个测试文件 171 用例全过，含新增 `constants.test.tsx` 4 用例
  （全字段完整格式 / display_name 缺失回退 / 版本缺失占位 / 无工艺来源退化）。
- `npm run build`：成功（chunk >500kB 告警为存量，041 已记录，非本次引入）。
- Playwright（`frontend/tests/049-create-task-loop-select.spec.ts`，`make dev` 环境）：
  下拉实际渲染 3 条选项全部命中格式 `^#\d+ .+（#\d+ \S+ \S+）$`，示例
  `#8 FEAT042-loop-1785394912590-440（#7 工艺统一-三列表 3.4.5）`。截图证据发 PR 评论，不入库。

## 5. 安全反思

- 改动为纯展示层文案拼装，无新接口、无权限路径、无用户输入落库，越权/注入风险面不变。
- label 数据来源为后端已注入的只读字段，antd Select 按文本渲染（非 HTML 注入），无 XSS 面。
- 所有新字段均为可选，旧数据（无工艺来源环路）走防御分支，显示与改动前一致，无兼容性风险。

## 6. 已知限制

- 长工艺名下拉行由 antd Select 默认省略号处理，未为此加宽弹窗（YAGNI）。
- label 含工艺信息后，antd Select 默认的 label 过滤顺带支持按工艺名搜索，属正向副作用，未做显式 `optionFilterProp` 配置。
