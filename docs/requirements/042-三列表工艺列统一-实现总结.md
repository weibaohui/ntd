# 042-三列表工艺列统一-实现总结

| 修改人 | 修改时间 | 修改内容 |
|--------|---------|---------|
| AI(Kimi) | 2026-07-30 | 初始版本 |

## 1. 实现内容

已把事项 / 任务 / 环路三个列表页的工艺展示统一为单列「工艺」，格式：

```text
#<工艺id>-<工艺名称>-<工艺版本>
```

无工艺来源显示 `-`。

## 5. 安全反思

- 后端只新增只读字段透出，不改变权限、不写库。
- SQL 仅补充 `COALESCE` 版本列，不改变 WHERE 条件与 workspace 过滤。
- 前端文本仍走 React 文本节点，无 HTML 注入面。

## 6. 已知限制

- 工艺 id 仍使用 `process_templates.id` 数值口径，未切换为 guid（与本次需求 `#<工艺id>` 的既有展示口径一致）。
- 缺版本时前端用 `—` 占位，保持三段式结构。
