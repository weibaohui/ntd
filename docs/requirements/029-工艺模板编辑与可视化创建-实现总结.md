### 2.3 处理流程

3. `serde_yaml` 结构校验（失败 400）
4. 原子写盘 + `import_user_process_templates` 刷新入库
5. DELETE 额外查询实例 Loop，非空则 409 + 数量

### 4.3 关键决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| Monaco 加载策略 | `loader.config({ monaco: MonacoNamespace })` 注入本地 monaco-editor | 离线可用 + 版本锁定，避免 CDN 依赖 |
| 错误标记 | `deltaDecorations` API 在行号槽标红波浪线 | Monaco 原生支持，覆盖 90% 场景 |
| 主题跟随 | 父组件传入 `theme: 'dark' \| 'light'`，映射 `vs-dark`/`vs` | 避免组件内重复 `useTheme` hook |
| 错误标记 CSS | 内联 `<style>` 注入 | 避免新增全局 CSS 文件 |
| YAML schema | `yaml.DEFAULT_SCHEMA`（JSON 兼容） | 工艺 YAML 只用基本类型；`DEFAULT_FULL_SCHEMA` 允许 `!!js/func` 不安全类型，且 @types/js-yaml 4.x 已移除该常量 |

### 4.4 系统工艺防护（三重）

1. Monaco `readOnly: true`
2. 顶部黄色 Alert "这是系统工艺，编辑后会被同步覆盖"
3. Alert 内嵌"复制到用户层后编辑"链接，点击调用 `bundledApi.copyProcessToUser(name)`

### 7.3 关键决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| React Flow 版本 | `@xyflow/react` ^12.3.0（v12 新包名） | 官方推荐，支持 parentId 子节点原生拖拽 |
| 父子节点 API | `parentId`（非 v11 的 `parentNode`） | v12 API 变更，Node.data 是 unknown 需 as 断言 |
| 节点 ID 约定 | `phase-${i}` / `link-${i}-${j}`（数组索引） | YAGNI，增删时索引变化导致重渲染；M5 可改用 phase.id/link.id |
| selectedNodeId 存什么 | YAML id（phase.id / link.id），非 React Flow 节点 id | 节点增删时索引变化，YAML id 稳定，属性面板能正确定位 |
| 双 source handle 颜色 | 绿 `#10b981` = on_success，橙 `#d97706` = on_gate_fail | 视觉编码与边颜色一致 |
| goto 边视觉 | on_success 绿色实线，on_gate_fail 橙色虚线 | 设计 §5.4.1 |
| 删除节点级联 | 集中在 `processDefinitionUpdater` 纯函数 | 单元测试覆盖，避免 UI 层重复逻辑 |
| 删除确认弹窗 | M4 用 `window.confirm` 简化 | M5 换成 Ant Design `Modal.confirm` |
| 布局算法 | dagre LR 横向 + phase 内 CSS flex 纵向 | 两层布局，phase 容器宽度固定 = NODE_WIDTH + PHASE_PADDING |

### 7.4 数据流（M4 单向，可视化 → ProcessDefinition）

```
ProcessEditor (父，维护 definition + selectedNodeId)
  ↓ definition
ProcessVisualEditor (React Flow)
  ├─ buildProcessGraph(definition, callbacks) → nodes + edges
  ├─ onConnect(connection) → setLinkGoto → onDefinitionChange
  ├─ onNodesDelete → removeLink（M5 启用）→ onDefinitionChange
  └ buildProcessGraph 重渲染
  ↓ definition + selectedNodeId
ProcessPropertyPanel (右侧)
  ├─ selectedNodeId 解析 → phase / link / global
  ├─ LinkPropertyForm → updateLinkField → onDefinitionChange
  ├─ PhasePropertyForm → updatePhaseField → onDefinitionChange
  └─ GlobalPropertyForm → 浅克隆 definition → onDefinitionChange
```

M4 不做的数据流（留给 M5）：
- 可视化操作 → `yaml.dump` 刷新 Monaco
- Monaco 编辑 YAML → `parseYaml` → 更新 `definition` → React Flow 重渲染
- 保存按钮 → `PUT /api/v1/processes/{name}`
