## 3. 前端看板详细设计

### 3.1 页面路由

```
/#/workspaces/{ws}/loops/{id}/execution-board/{eid}
```

### 3.2 页面布局

```
┌─────────────────────────────────────────────────────────┐
│ ← 返回 Loop Studio    Loop #42「标准交付」执行看板        │
│                                                        │
│ 进度：2/5 环节完成   返工：1次   状态：running           │
│                                                        │
├─────────────────────────────────────────────────────────┤
│ 需求（success）                                         │
│ ┌─────────────────────────────────────────────────────┐ │
│ │ ✅ 生成 PRD            rework=0                     │ │
│ │ 技能：4p12s-prd                                     │ │
│ │ 产物：PRD → docs/xxx-PRD.md                         │ │
│ │ 门禁：PRD 存在 ✅ | AI 评审 ✅ 85分                  │ │
│ └─────────────────────────────────────────────────────┘ │
│ ┌─────────────────────────────────────────────────────┐ │
│ │ ✅ 确认 PRD            rework=0                     │ │
│ │ 门禁：人工审批 ✅                                    │ │
│ └─────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────┤
│ 设计（running）                                         │
│ ┌─────────────────────────────────────────────────────┐ │
│ │ ⏳ 编写设计文档        rework=1                     │ │
│ │ 技能：write-design                                  │ │
│ │ 产物：design.md → 待捕获                             │ │
│ │ 门禁：文档存在 ⏳ | AI 评审 ⏳                         │ │
│ └─────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────┘
```

### 3.3 实现方式

- 复用 `antd` 的 `Collapse`（阶段折叠） + `Card`（环节卡片） + `Tag`（状态徽章） + `Table`（产物/门禁表格）；
- 从审计 API `GET .../audit` 一次性拉取全量数据；
- 数据流：`ProcessAuditDto` → 按 phase 分组 → 渲染卡片树。

## 4. 新增 API 设计

### 4.1 人工审批

```json
POST /api/v1/workspaces/{ws}/loops/{id}/executions/{eid}/steps/{seid}/gates/{gid}/approve
{
  "approved": true,
  "comment": "审批通过，可以进入下一阶段"
}

Response 200:
{
  "code": 0,
  "data": { "gate_id": 1, "status": "passed" }
}
```

### 4.2 手动补充产物

```json
POST /api/v1/workspaces/{ws}/loops/{id}/executions/{eid}/steps/{seid}/artifacts
{
  "name": "PRD",
  "artifact_type": "text",
  "locator": "## 产物",
  "content_text": "产物内容"
}

Response 201:
{
  "code": 0,
  "data": { "id": 1, "name": "PRD", ... }
}
```
