## 4. 关键设计决策与偏差记录

| 决策 | 原设计 | 实际实现 |
|------|--------|---------|
| 节点组件 | FlowStepNode 用 `variant` 参数区分 instance/template | FlowStepNode（instance）+ TemplateStepCard（template）两个独立组件 |
| 布局泛化 | `LayoutNode` 泛化为 `FlowLayoutStep` | LayoutNode 保持 LoopStepDto；ProcessFlowGraph 只用 positions Map |
| 适配器目标 | `utils/processFlowAdapter.ts` | `components/process/processFlowAdapter.ts`（与调用方同目录） |
| 阶段可视化 | 左侧色带 + 底部阶段名 | 每阶段上方彩色胶囊标签 + 阶段间虚线竖分隔 |
| goto 边 | 参与 dagre 布局 | 不参与 dagre（否则多行排列），SVG 正交折线独立绘制 |
| 边渲染 | 简单直线 | S 形贝塞尔 + SVG marker 箭头（对齐 FlowEdge 规范） |
| 样式对比 | variant 参数切换 | 两条独立组件路径，在边渲染层面已趋同，节点卡片各行其道 |
