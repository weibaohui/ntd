# 097 - 运行中心重构实现总结

## 关联

- 设计文档：[`docs/design/097-运行中心重构-设计.md`](../design/097-运行中心重构-设计.md)
- 方案：B（todo 看板归位「事项」菜单 + 独立「看板」菜单瘦身为「运行中心」+ 清理误导性 `memorial` 命名）

## 完成改动（4 块）

### 块 1：事项菜单加看板视图（todo 看板归位）
- `components/todo-list/TodoListPage.tsx`：`viewMode` 扩为 `card | list | kanban`；新增 kanban 渲染分支 `<KanbanBoard />`（不传 props，用其自带顶栏）。
- `components/todo-list/TodoListPageParts.tsx`（`TodoListHeader`）：Segmented 加看板选项（`ProjectOutlined`）；kanban 态走精简 header（仅 Segmented + 新建，避免与 KanbanBoard 顶栏重复）。

### 块 2：MemorialBoard → OpsCenter
- `git mv MemorialBoard.tsx → OpsCenter.tsx`；组件、title、icon、BoardMode 判断（`memorial`→`conclusion`）、Segmented（去「看板视图」、默认运行优先）、CSS 类名（`memorial-*`→`ops-*`）全部同步。

### 块 3：路由 / 导航 / 分发
- `hooks/useViewState.ts`：`View`/`BoardMode`/`ALL_VIEWS`/`ALL_BOARD_MODES`/`VIEW_TO_NAV_KEY`、3 处 fallback（`'memorial'`→`'running'`）、文件头路由注释表。
- `components/shell/LeftRail.tsx`：`LeftRailKey` + 菜单项（label「运行中心」+ `EyeOutlined`）。
- `App.tsx`：lazy import、`handleRailSelect`、视图分发。

### 块 4：CSS / 帮助 / onboarding / 注释
- `App.css`：`memorial-*` → `ops-*`（sed 批量，70+ 处）。
- `help/`：`memorial.md` → `ops.md`（git mv + 重写为三视图）；`board-mode-switch.md` 重写（四视图→三视图）；`board-*.md` 子文档 sed 清理 `MemorialBoard`/`memorial` 引用；`index.ts`/`HelpPage.tsx` pageId 同步。
- `onboarding/concepts.tsx`：节点 id/label/navTarget/drawerDesc 改运行中心；删 `GraphNode.navMode` 字段；execution highlights、连线、注释同步。
- `onboarding/ConceptRelationGraph.tsx`：`pushUrl` 去掉 `mode` 参数。
- 4 处注释 `MemorialBoard`→`OpsCenter`（`kanban/constants.ts`、`TimeRangeSegmented.tsx`、`TasksKanbanView.tsx`、`TasksPage.tsx`）。
