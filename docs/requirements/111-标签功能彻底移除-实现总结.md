# 111-标签功能彻底移除-实现总结.md

> 分支：feat/remove-tags-analysis
> 关联设计：docs/design/111-标签功能彻底移除-设计.md

## 1. 目标与范围

彻底移除标签（Tag）功能的前后端界面、模型、接口、数据库表、CLI 命令与文档。
用户确认：不做老数据迁移，旧库残留表就地废弃；旧备份 JSON 中的标签字段随代码移除自然被忽略。

## 2. 后端改动

| 文件 | 改动 |
|---|---|
| handlers/tag.rs、db/tag.rs、db/entity/{tags,todo_tags,loop_tags}.rs | 整文件删除 |
| db/entity/mod.rs、handlers/mod.rs、db/mod.rs、handlers/action.rs、cli/mod.rs | 移除模块注册、路由挂载（/api/v1/tags）与导出 |
| handlers/todo.rs | 移除 PUT /{id}/tags、创建时的 add_todo_tag、响应 tag_ids |
| handlers/loop_.rs | 移除 PUT /{id}/tags、list/get/status 的 tag 注入 |
| db/todo.rs | 移除 fetch_tag_ids_for_many、备份导出/导入/merge 的标签重建逻辑 |
| db/loop_.rs | 移除 copy_todo_to_workspace 的标签复制 |
| db/dashboard.rs、db/execution.rs | 移除 total_tags / tag_distribution 统计与两个 fetch 函数 |
| handlers/backup.rs、handlers/sync.rs | 移除备份与云同步的标签字段 |
| models/todo.rs、models/loop_.rs、models/execution.rs | 删除 Tag/CreateTagRequest/UpdateTagsRequest/TagBackup/TagCount 与 DTO 的 tag_ids/tag_names；伪 ID 前缀去掉 "tag" |
| cli/commands.rs、main.rs | 删除 ntd tag 子命令、--tags/--tag 参数与 handle_tag |
| db/migration/{consolidated_schema,v1,v41_v46,v80}.rs | 删除 tags/todo_tags/loop_tags/step_tags 建表、索引与触发器（合并 schema 与增量迁移保持一致） |
| 其余构造点 | installer.rs / pre_spawn.rs / auto_review.rs 等 Todo 字面量去掉 tag_ids |

4. Playwright 冒烟：设置页无「标签管理」Tab、事项抽屉无标签选择、仪表盘无标签图表。
