# 实现总结：环路列表展示工艺信息 + 新建任务下拉区分环路（041）

## 1. 概述

围绕「同一工艺可被安装成多个同名环路」的痛点做两处修复：

- **环路列表页**（`/#/loops`）新增「工艺名称」「版本」两列，让用户一眼看出环路来自哪个工艺、哪个版本；
  仅工艺安装的环路有值，手工环路显示 `-`。
- **新建任务 Modal**（`/#/tasks`）环路下拉选项改为 `#<环路ID> <环路名称>`，凭 ID 区分同名环路。

设计文档：`docs/design/041-环路列表工艺信息与任务下拉区分-设计.md`。

## 2. 后端改动

### 2.1 批量查询（`backend/src/db/process_template.rs`）

新增 `get_process_templates_by_ids(ids: &[i64]) -> Vec<process_templates::Model>`，
`Entity::find().filter(Column::Id.is_in(...))` 一次取回，避免逐 loop N+1；空入参短路返回空 Vec。

### 2.2 列表接口注入工艺名称（`backend/src/handlers/loop_.rs::list_loops_v1`）

在现有 `with_tags` 注入的同位置：收集所有非空 `process_template_id`（去重）→ 批量查模板建
`HashMap<i64, Model>` → 对每条 loop 调 `LoopDto::with_process_template`（操作 `LoopListItem.loop_` 字段）。
`process_template_version` 由 `LoopDto::from(loops::Model)` 自动带出，无需额外处理。

> v0 `list_loops` 前端不再调用，未改（YAGNI）。
