## 落地

### 1. 事项菜单加 running 态（第 4 视图）
- `todo-list/TodoListPage.tsx`：`viewMode` 扩为 `card | list | kanban | running`；running 态 `<RunningBoard />`（不传 props，靠自带统计栏 + 实时 WS + 评审流水线）。
- `todo-list/TodoListPageParts.tsx`（TodoListHeader）：Segmented 加「执行监控」选项（`ThunderboltOutlined`）；running 态精简顶栏（只 Segmented + 新建，与 kanban 一致）。

### 2. 环路菜单加 kanban 态（第 2 视图）
- `loop-list/index.tsx`：`viewMode` 新增 `list | kanban`（localStorage `ntd_loops_view`）+ `hours` state；kanban 态 `<LoopKanban searchText hours onOpenTodo />`；`handleOpenTodo` 跳事项详情。
- `loop-list/LoopListPageParts.tsx`（LoopListHeader）：加视图切换 Segmented + 时间窗（kanban 态显示）；list 态保留配置/刷新，kanban 态隐藏（LoopKanban 自拉数据）。
- **维度差异**：list = loop 定义管理，kanban = loop 执行历史，切换换数据对象（按决策不标注，用户自行感知）。

### 3. OpsCenter 拆解 + 路由清理
- 删 `components/OpsCenter.tsx`（运行中心菜单消失）。
- `App.tsx`：lazy import + `handleRailSelect` + 视图分发 去 OpsCenter/ops。
- `shell/LeftRail.tsx`：去「运行中心」菜单项 + `LeftRailKey` 去 `'ops'` + import 清理。
- `hooks/useViewState.ts`：`View` 去 `'ops'`；**整个 BoardMode 体系删除**（类型 / ALL_BOARD_MODES / getInitialBoardMode / boardMode state / setters / return / syncStateFromOptions / syncFromHash / NavOpts.mode / buildHashUrl mode 处理 / VIEW_TO_NAV_KEY）。

### 4. onboarding + help 同步
- `onboarding/concepts.tsx`：删 ops 节点（运行中心）+ execution highlights 去 'ops' + execution→ops 连线 + 注释更新（观察层只剩黑板）。
- `help/index.ts`：删 ops page 条目（含 6 个 board-* features）。
- `help/HelpPage.tsx`：pageIds 去 'ops'。
- 删 `help/pages/ops.md` + 6 个 `board-*.md`（运行中心功能文档集）。
- 注释清理（OpsCenter→原运行中心）：`TasksKanbanView.tsx` / `TasksPage.tsx` / `TimeRangeSegmented.tsx` / `kanban/constants.ts`。

## 已知事项

- **事项 4 态**：card/list/kanban/running，Segmented 横向空间紧（用 ThunderboltOutlined 差异化 + tooltip 缓解）。
- **维度混置**：事项 running 态执行记录卡（同 todo 多张）与 card/kanban 的 todo 定义卡心智不同；环路 list/kanban 维度不同——按决策不标注。
- **conclusion 删除**：「最近 N 小时已完成瀑布流」能力降级为事项 card + 已完成筛选（无时间窗），如需时间窗后续给 card 加。
- **旧 URL 失效**：`/#/ops` 及 `?mode=running|loop_kanban|conclusion` 全失效，回退事项。
- 纯前端重构，后端无改动。
