## 1. 核心改动

| 改动点 | v1 | v2 |
|--------|----|----|
| 任务创建 | 每次创建新 Loop | 检测复用，同模板+同空间返回已有 Loop |
| 需求存储 | loops.description | loop_executions.trigger_meta.requirement |
| 需求更新 | 覆盖 loops.description | 每次执行独立写入 |
| LoopRunner 替换 | replace("{{requirement}}", &loop_.description) | replace("{{requirement}}", trigger_meta.requirement) |
| 任务列表 | 仅状态 | 状态 + 最新需求 |

---

## 2. 后端改动

### 2.1 handlers/tasks.rs

**create_task**：增加复用检测。

```rust
// 1. 检测复用
let loop_id = if let Some(existing) = db.find_task_loop(template_id, ws_id) {
    existing  // 复用
} else {
    install_process_template(...)  // 新建
};
// 2. 创建执行，需求写入 trigger_meta
let exec_id = db.create_loop_execution(loop_id, ..., 
    &json!({"requirement": req.requirement}).to_string(), ...);
// 3. 返回
return { task_id: loop_id, execution_id: exec_id };
```

**list_tasks**：增加子查询取最新需求。

```sql
SELECT ..., 
  (SELECT le.trigger_meta FROM loop_executions le WHERE le.loop_id=l.id 
   ORDER BY le.started_at DESC LIMIT 1) AS latest_trigger_meta
```

### 2.2 LoopRunner

从 trigger_meta 读需求（替代从 loop_.description 读）。

```rust
let requirement = trigger_meta.get("requirement").and_then(|v| v.as_str()).unwrap_or("");
let enhanced_prompt_raw = todo.prompt
    .replace("{{requirement}}", requirement);
```

### 2.3 db/loop_.rs

新增 `find_task_loop(template_id, workspace_id) -> Option<i64>`。

## 3. 前端改动

### 3.1 TasksPage.tsx

任务卡片增加需求预览：

```tsx
// 从 latest_execution_status 旁增加 latest_requirement
{task.latest_requirement && (
  <Text type="secondary" ellipsis>{task.latest_requirement.slice(0, 60)}</Text>
)}
```

### 3.2 TaskDetailPage.tsx

- 「新建执行」按钮 → 弹出 Modal 输入需求 → 调 create_task (复用 Loop) → 触发执行
- 执行历史每行显示 `requirement` 文本

### 3.3 API (bundled.ts)

- `createTask`：增加 `requirement` 参数，返回 `{ task_id, execution_id }`
- `listTasks`：增加 `latest_requirement` 字段
