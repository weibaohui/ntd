# 042-三列表工艺列统一-设计

| 修改人 | 修改时间 | 修改内容 |
|--------|---------|---------|
| AI(Kimi) | 2026-07-30 | 初始版本 |

## 目标

把事项 / 任务 / 环路三个列表页的工艺展示统一为一列：`工艺`，文本格式为 `#<工艺id>-<工艺名称>-<工艺版本>`。

## 现状

- 事项：`TodoListView.renderProcessColumn` 已按模板去重，但格式是 `#模板ID 模板名`；`LoopRefSummary` 不带版本。
- 任务：`TasksTableView` 只有 `template_name`；后端 `TaskItem` 未返回 `template_version`。
- 环路：`LoopListViewParts` 有「工艺名称」「版本」两列；需合并为一列。

## 方案

### 1. 统一文本构造函数

新增 `frontend/src/utils/processText.ts`：

```ts
formatProcessText(id, name, version): string
```

规则：

- `id == null` → `-`
- `name` 为空 → 回退 `#<id>`
- `version` 为空 → 回退 `—`
- 否则返回 `#<id>-<name>-<version>`

新增 `frontend/src/utils/processText.test.ts` 覆盖：完整字段、缺 name、缺 version、无 id。

### 2. 后端补齐版本字段

- `models::LoopRefSummary` 增加 `process_template_version: Option<String>`。
- `db::loop_::get_referencing_loops_for_todos` SQL 增加 `COALESCE(l.process_template_version, pt.version) as process_template_version`；分组函数读取该字段。
- `handlers::tasks::TaskItem` 增加 `template_version: Option<String>`，列表接口从 `process_templates.version` 透出。

### 3. 前端三列表统一

- 事项 `TodoListView.renderProcessColumn`：仍按 `process_template_id` 去重，每个 Tag 改为 `formatProcessText(id, name, version)`。
- 环路 `LoopListViewParts`：删除「工艺名称」「版本」两列，替换为单列「工艺」；新增 `loopProcessText(record)` 调 `formatProcessText`。
- 任务 `TasksTableView`：列名「工艺模板」改为「工艺」，渲染改为 `formatProcessText(template_id, template_name, template_version)`；`TaskItem` 类型补 `template_id/template_version`。

### 4. 测试

- 新增 `processText.test.ts`。
- 更新 `TodoListView.test.tsx` 的工艺列期望格式。
- 更新 `LoopListViewParts.test.tsx`：从「名称/版本两列」改为「工艺列统一文本」。
- Playwright 回归 `ntd006/ntd007/ntd009`，确保既有 tasks 页交互不受影响。

## 非目标

- 不调整工艺模板市场、详情页面包屑、环路升级逻辑。
- 不改变工艺 id 的既有数值口径（仍用 `process_templates.id`，不切换为 guid）。
