# 093-任务详情 Tab 显隐逻辑抽纯函数重构-设计

| 修改人 | 修改时间 | 修改内容 |
|--------|---------|---------|

关联前序：`docs/design/093-任务详情环路Tab按执行方式显隐-设计.md`（该功能已合入 PR #998）。

## 1. 背景

前序功能（委派任务隐藏「执行环路」「执行历史」Tab）的实现把两件事揉在了 `TaskDetailPanel.tsx` 的 JSX 里：

1. **显隐规则**：`const isDelegate = task.execution_mode === 'delegate'`，再用条件展开 `...(!isDelegate ? [dag, exec] : [])` 组装 `tabItems`；
2. **activeKey 回退**：`tabItems.some(t => t.key === resolvedTab) ? resolvedTab : (isDelegate ? 'discussion' : 'overview')`。

问题：这两段都是纯逻辑（输入 execution_mode / preferred tab，输出可见集合 / 生效 key），却只能随组件一起渲染、无法单独测试。`/review 998` 也曾指出 `TaskDetailPanel` 主体过长、tab 组装逻辑可读性不佳。

## 2. 目标与非目标

- **目标**：把「Tab 显隐」与「activeKey 回退」抽成纯函数 + vitest 单测，让组件回归声明式渲染。
- **非目标（刻意不做）**：不动 `TaskDetailPanel` 的两个数据加载 `useEffect`（拉任务详情、拉环路详情）——那是组件里最大的 bug 风险源，与本次显隐重构无关，混在一起改会放大风险。TaskDetailPanel 主体超长问题不在本次范围。

## 3. 设计

### 3.1 新增纯函数（`frontend/src/components/tasks/helpers.ts`）

该文件原本只承载执行历史时间格式化（`execDurationSec` / `formatExecTimeInfo`），其头部注释已声明「抽纯函数脱离组件做单测、让 JSX 保持声明式」的定位，与本次新增同源，故就地扩入。

- `TaskTabKey`：`'overview' | 'dag' | 'exec' | 'discussion'` 类型，作为 Tab key 单一来源。
- `visibleTaskTabs(executionMode?)`：委派→`['overview','discussion']`；其余（loop 或历史无字段旧任务）→全部 4 个。与既有「非委派即展示」口径一致。
- `resolveTaskActiveTab(preferred?, executionMode?)`：preferred 命中可见集合才采纳，否则回退默认（委派→discussion，其余→overview）。preferred 非 Tab key（如 `?tab=garbage`）同样回退。

### 3.2 组件改造（`TaskDetailPanel.tsx`，~388-440 行）

- `allTabs`：声明式平铺全部 4 个 Tab 的内容定义（不再用条件展开塞/抽 dag、exec）。
- `tabItems = allTabs.filter(t => visibleKeys.includes(t.key))`：按执行方式过滤。顺序仍遵循 `allTabs` 声明顺序（`visibleTaskTabs` 仅作成员集合判断）。
- `activeTabKey = resolveTaskActiveTab(resolvedTab, task.execution_mode)`：替换原先就地 `some + 三元`。
- 移除仅服务于旧逻辑的局部变量 `isDelegate`（Header / 隐藏「再次执行」/ 默认 Tab 等处仍各自内联 `execution_mode === 'delegate'`，未受影响）。
- `TAB_KEYS` 与 `resolvedTab` 保留不动：`resolvedTab` 先据白名单兜底一轮，`resolveTaskActiveTab` 再做「可见集合」收口，两层职责清晰、行为不变。

### 3.3 单测（`helpers.test.ts`）

`visibleTaskTabs`（3 条）：委派隐藏 dag/exec、工艺环路全展示、undefined 旧任务全展示。
`resolveTaskActiveTab`（6 条）：偏好命中采纳、委派下偏好 dag/exec 回退 discussion、委派下 discussion 命中、工艺环路偏好省略回退 overview、偏好非 Tab key 回退 overview。
