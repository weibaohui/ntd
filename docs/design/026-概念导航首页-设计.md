## 1. 设计目标

把 ntd 的 6 个核心概念（工艺/环路/事项/任务/执行器/专家）用**可交互的可视化**讲清楚，让新用户 3 分钟理解系统全貌，老用户可随时回看。复用现有 `PageCard`/`useViewState`/`bundledApi` 体系，不引入新重依赖。

## 4. 关键设计决策

### 4.1 关系图用纯 SVG，不引入 reactflow

**决策**：节点坐标硬编码在 `concepts.ts`，连线用 SVG `<path>` + `stroke-dasharray` 流动。

**理由**：
- 节点数固定 7 个（4 主 + 3 支线），不需要 reactflow 的拖拽/缩放/自动布局
- 纯 SVG 包体积 0，reactflow + 依赖约 80KB
- 关系图是只读可视化，不是编辑器，YAGNI

**代价**：节点坐标不响应式重排，小屏幕溢出 → 用容器 `overflow-x: auto` 兜底。

### 4.2 数据快照用并行请求

**决策**：`useConceptCounts` hook 用 `Promise.all` 并行拉取 6 个概念的数量 + 快速开始 5 步完成状态。

**理由**：串行请求 6 个 API 总耗时 ~6 × 200ms = 1.2s，并行 ~200ms，首屏体验更好。

**实现**：
```ts
const [counts, setCounts] = useState<ConceptCounts | null>(null);
useEffect(() => {
  Promise.all([
    bundledApi.getProcesses(),
    dbLoops.listLoops(wsId),
    db.getAllTodos(wsId),
    bundledApi.listTasks(wsId),
    db.getExecutors(),
    db.getExperts(),
  ]).then(([procs, loops, todos, tasks, execs, exps]) => {
    setCounts({
      process: procs.length,
      loop: loops.length,
      todo: todos.length,
      task: tasks.length,
      executor: execs.length,
      expert: exps.length,
    });
  });
}, [wsId]);
```

### 4.3 首次跳转逻辑放 App.tsx，不放 useViewState

**决策**：在 `App.tsx` 顶层 `useEffect` 检测 localStorage，不存在则 `replaceUrl('onboarding')`。

**理由**：
- `useViewState` 只管 URL ↔ state 同步，不该含「首次进入」业务逻辑
- App.tsx 是应用入口，适合放一次性引导逻辑
- 用 `replaceUrl` 不用 `pushUrl`：不污染历史栈，用户点返回不会回到 onboarding

### 4.4 详细说明区数据快照只拉一条

**决策**：每个概念的详细说明区只拉一条真实记录展示，不展示全量列表。

**理由**：
- 全量展示会变成「另一个工艺页/环路页」，偏离导航首页职责
- 一条记录足以让用户理解字段含义
- 空态时展示「暂无数据，去 XX 页创建」+ 跳转按钮

### 4.5 sticky Tab 用 IntersectionObserver

**决策**：三个 `<section>` 各加 `id` + `data-tab-key`，`IntersectionObserver` 监听进入视口的 section，自动高亮 Tab。

**理由**：
- 比 `onScroll` 监听 `scrollTop` 判断更精准、性能更好
- 所有现代浏览器支持，不需 polyfill（YAGNI）

### 5.3 `ConceptRelationGraph.tsx`

```tsx
export function ConceptRelationGraph() {
  const [hovered, setHovered] = useState<string | null>(null);
  const [drawerConcept, setDrawerConcept] = useState<ConceptNode | null>(null);
  const reduceMotion = usePrefersReducedMotion();

  return (
    <>
      <svg viewBox="0 0 1000 400" style={{ width: '100%', overflow: 'auto' }}>
        {/* 连线：path + stroke-dasharray 流动动画 */}
        {GRAPH_EDGES.map(edge => <Edge ... />)}
        {/* 节点：g + circle + text */}
        {GRAPH_NODES.map(node => (
          <GraphNode
            key={node.id}
            node={node}
            hovered={hovered}
            onHover={setHovered}
            onClick={() => setDrawerConcept(CONCEPTS.find(c => c.id === node.id))}
          />
        ))}
      </svg>
      <Drawer open={!!drawerConcept} onClose={() => setDrawerConcept(null)} width={480}>
        {drawerConcept && <ConceptDrawerContent concept={drawerConcept} />}
      </Drawer>
    </>
  );
}
```

**函数拆分**：
- `ConceptRelationGraph`：主组件，SVG + Drawer
- `Edge`：单条连线，流动动画（`stroke-dashoffset` keyframes）
- `GraphNode`：单个节点，hover 高亮 + 点击触发 Drawer
- `ConceptDrawerContent`：Drawer 内容，定义 + 字段表 + 跳转按钮
- `usePrefersReducedMotion`：检测 `prefers-reduced-motion`（新增小 hook 或复用现有）

## 11. 错误处理

| 场景 | 处理 |
|------|------|
| API 拉取失败 | `counts` 对应字段设为 `null`，徽标不显示，不阻塞页面 |
| 数据快照为空 | 展示 `<Empty>` + 「去 XX 页创建」按钮 |
| 关系图小屏溢出 | 容器 `overflow-x: auto`，用户可横向滚动 |
| IntersectionObserver 不触发 | Tab 仍可点击手动切换，不依赖自动高亮 |

## 12. 安全反思

- ✅ 只读页面，不修改任何数据
- ✅ 不展示敏感字段（数据快照过滤 `app_secret`/`bot_open_id`/`app_id` 等）
- ✅ 数据快照只展示当前 workspace，不跨 workspace
- ✅ 跳转按钮用 `pushUrl`（hash 路由），不构造可注入 URL
- ✅ 无用户输入，无 XSS 风险
- ✅ localStorage 标记读写包裹 try/catch，静默降级

---

## 13. 已知限制

1. 关系图节点坐标硬编码，不响应式重排（小屏 overflow 兜底）
2. 数据快照只拉一条记录，不展示全量
3. 不做概念编辑功能（只读导航）
4. 不做移动端独立组件（降级为纵向布局）
5. IntersectionObserver 不做 polyfill（所有现代浏览器支持）
