## 1. Migration V73

```sql
-- 1. 新建 tasks 表
CREATE TABLE IF NOT EXISTS tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL DEFAULT '',
    description TEXT NOT NULL DEFAULT '',
    status TEXT NOT NULL DEFAULT 'pending',
    workspace_id INTEGER,
    template_id INTEGER,
    loop_id INTEGER,
    created_by TEXT DEFAULT '',
    created_at TEXT,
    updated_at TEXT
);

-- 2. loops +task_id
ALTER TABLE loops ADD COLUMN task_id INTEGER;

-- 3. loop_executions +task_id
ALTER TABLE loop_executions ADD COLUMN task_id INTEGER;
```

（用 add_column_if_missing 保证幂等）

## 2. 后端改动

### 2.1 handlers/tasks.rs

```rust
// POST /api/v1/tasks
pub async fn create_task(req: CreateTaskRequest) {
    // 1. 选模板
    // 2. 创建 task 记录
    let task = db.create_task(&title, ws_id, template_id, /*loop_id 稍后填*/).await?;
    // 3. 检测/创建 Loop
    let loop_id = if let Some(existing) = db.find_task_loop(template_id, ws_id).await? {
        existing
    } else {
        install_process_template(...).loop_id
    };
    // 4. 回填 task.loop_id
    db.update_task_loop_id(task.id, loop_id).await?;
    // 5. 创建执行（带 task_id）
    let exec = db.create_loop_execution_with_task(loop_id, task.id, &trigger_meta).await?;
    // 6. 返回
    { task_id: task.id, loop_id, execution_id: exec.id }
}

// GET /api/v1/tasks
pub async fn list_tasks(status: Option<&str>) {
    SELECT t.*, pt.name as template_name, pt.complexity FROM tasks t
    LEFT JOIN process_templates pt ON pt.id = t.template_id
    WHERE (?1 IS NULL OR t.status = ?1)
    ORDER BY t.created_at DESC
}

// GET /api/v1/tasks/{id}
pub async fn get_task(id: i64) {
    SELECT t.*, pt.* FROM tasks t JOIN process_templates pt ...
     + loop_executions WHERE task_id = t.id
}
```

### 2.3 状态自动更新

LoopRunner 在 loop 执行结束后，更新对应 task 的 status：

```rust
// loop_runner.rs::spawn_run 中，loop 执行完成后
if let Some(task_id) = loop_exec.task_id {
    let new_status = match run_result {
        Ok(LoopRunOutcome::Finished) => { /* success/failed based on final_status */ },
        ...
    };
    db.update_task_status(task_id, new_status).await;
}
```
