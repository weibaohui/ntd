# 111-标签功能彻底移除-设计.md

> 状态：已获确认（2025-XX）
> 关联需求：无（纯删除）
> 分支：feat/remove-tags-analysis

## 1. 背景与目标

标签（Tag）功能当前渗透在 todo / loop / dashboard / backup / sync / CLI 多处。经完整影响面分析后确认：
标签不是任务执行核心链路的组成部分，仅是可选的「打标 + 展示」增强。

本次目标：**彻底移除标签功能的前后端界面、模型、接口、数据库表、CLI 命令与文档**。

## 2. 范围确认（用户已确认）

- 范围：全部删除——含设置页「标签管理」、todo/loop 打标与展示、仪表盘标签统计、
  备份/云同步中的标签字段、CLI `ntd tag` 子命令。
- 存量数据：**不写迁移**。老库残留 tags/todo_tags/loop_tags/step_tags 表就地废弃，
  新库（consolidated_schema）不再创建这些表。
- 旧备份兼容：删除解析逻辑，旧备份 JSON 中的 tags/tag_names 字段随代码移除自然被忽略。
