# 049-新建任务下拉显示工艺信息-设计

| 修改人 | 修改时间 | 修改内容 |
|--------|---------|---------|
| pi | 2026-07-31 | 初始版本 |

> 关联需求：`docs/requirements/049-新建任务下拉显示工艺信息-需求.md`

## 1. 背景

041 后端已在 `list_loops_v1` 注入工艺字段（`LoopDto::with_process_template`），前端 `LoopListItem` 类型也有这些字段；只是 `TasksPage` 映射为 `LoopLite` 时裁掉了。因此本需求是**纯前端数据透传 + 文案拼装**，零后端改动。

## 2. 决策

**复用既有数据链路，新增一个纯函数负责 label 拼装**（与 041 的 `loopProcessText` 同模式：纯函数便于单测）。

不直接复用 `formatProcessText` 的原因：其输出为 `#id-名称-版本`（中划线分隔，面向表格列）；用户需求格式为 `#id 名称 版本`（空格分隔，括号内嵌在下拉行内）。仅复用其**回退口径**（display_name→name→`#id`；版本缺失 `—`），不复用其分隔符。

## 3. 详细设计

### 3.1 `frontend/src/components/tasks/constants.tsx`

- `LoopLite` 扩展 4 个可选字段（与 `LoopListItem` 同名对齐，可选保持向后兼容）：
  `process_template_id?` / `process_template_display_name?` / `process_template_name?` / `process_template_version?`
- 新增纯函数 `loopOptionLabel(l: LoopLite): string`：
  1. 基础段 `` `#${l.id} ${l.name}` ``（041 格式）；
  2. `process_template_id == null` → 直接返回基础段（防御分支，当前调用方已过滤）；
  3. 名称 = `display_name ?? name`，trim 后为空则用 `#<工艺ID>` 兜底；
  4. 版本 trim 后为空用 `—` 占位；
  5. 返回 `` `${base}（#${pid} ${pname} ${version}）` ``（全角括号，与需求格式一致）。

### 3.2 `frontend/src/components/tasks/TasksPage.tsx`

`setLoops` 的 `.map()` 透传 4 个工艺字段（filter 逻辑不变）。

### 3.3 `frontend/src/components/tasks/CreateTaskModal.tsx`

Select `options` 的 `label` 由模板字符串改为 `loopOptionLabel(l)`；其余（value、notFoundContent、testid）不动。

### 3.4 单元测试 `frontend/src/components/tasks/constants.test.tsx`（新增）

`loopOptionLabel` 4 个用例：
1. 全字段 → 完整格式（display_name 优先）；
2. display_name 缺失 → 回退 process_template_name；
3. 版本缺失 → `—` 占位；
4. 无 process_template_id → 退化 041 格式。

## 4. 不做的

- 不改后端（041 已注入字段，YAGNI）。
- 不改环路列表/事项列表的工艺列（042 已统一为 `formatProcessText`）。
- 不改下拉 value 与提交逻辑。

## 5. 测试

- vitest：`constants.test.tsx` 4 用例（见 3.4）。
- 编译：`npx tsc --noEmit` 零错误、`npm run build` 无新告警。
- UI：`make dev` 后 Playwright 打开 `/#/tasks` → 新建 → 展开下拉，断言选项文本匹配 `#\d+ .+（#\d+ .+ .+）`；截图证据发 PR 评论（不入库）。

## 6. 风险

- **label 变长**：Modal 宽 560px，长工艺名下拉行可能换行/截断——antd Select 默认省略号处理，可接受；不为此加宽弹窗（YAGNI）。
- **无数据兼容性风险**：字段均为可选，旧环路（无工艺来源）走防御分支，显示与改动前一致。
