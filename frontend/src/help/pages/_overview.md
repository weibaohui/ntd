# 欢迎使用 ntd

ntd（Now Task, Done）是一个 AI 驱动的任务引擎。它把「工艺 → 环路 → 事项 → 任务 → 执行器 → 专家」串成一条可自动运转的流水线，让你从「手动安排每一件事」升级到「设计规则、让 AI 执行」。

## 你能在这里做什么

| 想做的事 | 去哪个页面 |
|---------|-----------|
| 看全局运营态势（执行量、成本、成功率） | 仪表盘 |
| 理解 NTD 的 6 个核心概念 | 导航（概念首页） |
| 管理任务、事项、环路 | 工作（任务 / 事项 / 环路 / 工艺） |
| 看消息流、黑板内容、看板 | 观察（消息 / 黑板 / 看板） |
| 配置执行器、专家、技能、工作空间 | 配置（技能 / 专家 / 执行器 / 智能助手 / 工作空间 / 更多设置） |

## 怎么用这个帮助

1. 左侧菜单按「概览 / 工作 / 观察 / 配置」分组，点任意条目，右侧展示对应帮助。
2. 每篇帮助包含四部分：**在这里做什么**（场景定位）、**怎么操作**（步骤指引）、**操作后会发生什么**（结果说明）、**常见问题**（边界与坑）。
3. 涉及数据流转的页面会配一张 Mermaid 流程图，深色/浅色主题自动适配。

## 上手建议

- **新用户**：先看「导航（概念首页）」理解概念，再看「快速开始 5 步」跑通第一条流水线。
- **老用户**：直接在左侧菜单定位你遇到的页面，查对应功能点的操作说明。
